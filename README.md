# SchoolHub Manager - Windows Setup

School management software for Pakistani schools (multi-school: students, fees,
attendance, exams, salaries, transport, library, reports). Yeh repository sirf
Windows installer banati hai; app ka source code private repository mein hai.

## Download aur install

1. **Releases** se latest `SchoolHub-Manager-Setup.exe` download karein.
2. Setup chalayein. Windows "Unknown publisher" dikha sakta hai (installer
   signed nahi hai) - **More info > Run anyway**.
3. Desktop par **SchoolHub Manager** shortcut aa jayega. Double-click karein -
   browser mein app khul jayegi.
4. Pehla login: username/password
   `%LOCALAPPDATA%\SchoolHub\data\bootstrap-superadmin.txt` file mein hota hai.
   Login ke baad app apna naya password set karwati hai.

- App isi computer par locally chalti hai (kisi internet server ki zarurat nahi).
- Sab data `%LOCALAPPDATA%\SchoolHub\data` mein rehta hai; uninstall data delete
  nahi karta.
- Band karne ke liye Start Menu > SchoolHub Manager > **Stop SchoolHub**.
